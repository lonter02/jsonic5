jsonic: because JSON is boring🔗ℹ

1 Introduction🔗ℹ

Roxy Lexington

 #lang jsonic5 package: jsonic5

This is a domain-specific language. that relies on the json library. In particular, the jsexpr->string function.

If we start with this:

#lang jsonic

[

@$ 'null $@,

@$ (* 6 7) $@,

@$ (= 2 (+ 1 1)) $@

]

We’ll end up with this:

[

null,

42,

true

]
